# 🎮 2048 Game

A simple and fun browser-based **2048 Puzzle Game** built using HTML, CSS, and JavaScript.

## ✨ Features

- 🎯 Classic 2048 gameplay
- ⌨️ Keyboard controls
- 📱 Responsive design
- 🔄 Restart game option
- 🏆 Score tracking
- ⚡ Fast and lightweight

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
